# Quiz Arena – setup
1. Open this folder in Android Studio (it will create the Gradle wrapper on sync).
2. Firebase console: create a project -> add Android app with package `com.example.quizapp`
   -> add your debug SHA-1 -> Authentication > Sign-in method > enable **Google**.
3. Download `google-services.json` into `app/`.
4. Run on a device/emulator with Google Play services.

Test QR text: `category=9;difficulty=easy`  (any QR generator will do)
